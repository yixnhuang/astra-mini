# Astra Mini

Astra Mini is the single-page edition of Astra: Adaptive Site Template for Research and Academia. Its visual system and page structure are derived directly from the Astra source website.

## Overview

The template contains one academic homepage with profile, education, experience, and selected-project sections. It follows the browser or operating-system color preference automatically and does not expose theme controls.

## Features

- One HTML page
- Original Astra layout, typography, spacing, colors, and responsive rules
- Automatic light and Michigan-dark appearance
- Neutral SVG placeholders for personal assets
- No framework or build step

## Usage

```bash
git clone https://github.com/yixnhuang/astra-mini.git
cd astra-mini
python -m http.server 8000
```

Open `http://localhost:8000` and replace the sample content in `index.html`.
