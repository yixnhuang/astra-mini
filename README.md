# Astra Mini

Astra Mini is the one-page edition of Astra: Adaptive Site Template for Research and Academia. It provides a small, dependency-free starting point for a research or academic homepage.

## Overview

The template keeps a profile, research interests, education, selected work, and contact details on one page. Its colors follow the browser or operating-system theme automatically. No theme control is included.

## Features

- Single responsive page
- Automatic light and dark appearance
- Semantic HTML and accessible focus styles
- No framework, build step, JavaScript, or external asset

## Requirements

- A modern web browser
- Any static web host

## Usage

Clone the repository and edit the sample content in `index.html`.

```bash
git clone https://github.com/yixnhuang/astra-mini.git
cd astra-mini
```

Open `index.html` directly or serve the directory with a local static server.

## Project Structure

```text
.
├── index.html
├── style.css
├── LICENSE
└── README.md
```

## Customization

Replace the sample name, biography, links, education, and work. The appearance is intentionally fixed and follows `prefers-color-scheme`; the template does not provide user-selectable themes.

## Deployment

Upload the four repository files to a static host. No build command is required.
